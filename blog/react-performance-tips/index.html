5 React Performance Patterns Every Developer Should Know

Performance isn't premature optimization — it's user trust. These five patterns solve the re-render problems that show up in every growing React codebase.

React's declarative model makes building UIs fast — until a dashboard with filters, tables, and charts starts stuttering on mid-range laptops. The fix usually isn't rewriting in another framework. It's applying a handful of patterns consistently.

1. Colocate State Where It's Used

Lifting state to the root feels convenient early on, but it forces unrelated branches to re-render. Keep state as close as possible to the components that consume it. If only a sidebar filter needs searchQuery, don't store it in a global context used by the entire app.

2. Memoize Expensive Computations with useMemo

Deriving sorted lists, grouped data, or chart series on every render adds up. Wrap heavy derivations in useMemo so they only recompute when dependencies change — not when an unrelated modal opens.

3. Stabilize Callbacks with useCallback

Child components wrapped in React.memo still re-render when parents pass fresh inline functions each render. useCallback preserves referential equality for handlers passed deep into list items or memoized children.

4. Code-Split Routes with React.lazy

Users shouldn't download your admin panel to view a landing page. Split routes at the page level:

const Dashboard = React.lazy(() => import('./Dashboard'));

function App() {
  return (
    <Suspense fallback={<Spinner />}>
      <Routes>...</Routes>
    </Suspense>
  );
}

5. Virtualize Long Lists

Rendering 5,000 table rows DOM nodes will choke any browser. Libraries like @tanstack/react-virtual or react-window render only what's visible, keeping scroll performance smooth for transaction histories and activity feeds.

Measure Before You Optimize

React DevTools Profiler and the browser Performance tab tell you what's actually slow. Avoid sprinkling memo everywhere — it has a cost too. Profile first, then apply the pattern that matches the bottleneck.

Takeaway

Great React performance is mostly discipline: local state, intentional memoization, lazy routes, and virtualized lists. Master these five and your apps will feel instant long before you need exotic optimizations.
